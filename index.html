How it works

  1. The file is split into numbered chunks.
  2. Each frame on screen is a QR code carrying one chunk — or an XOR blend of several.
  3. The other device watches with its camera and rebuilds the file from whatever it manages to catch.

Missed frames are expected and cost nothing. The stream is endless: keep it running until the receiver says it's done.
